# These documents are history, not plan

Everything in this folder was written for the caregiver marketplace: how to
recruit carers, how to verify them, how to price visits, how to build a doctor
directory, how the unit economics work at scale.

**That product was abandoned on 1 August 2026.** It could not exist without
recruiting and paying caregivers, and there was no way to do either. CareHive
is now a medicine record — see the README at the repo root for what it actually
does. Nothing here describes the app that exists.

The documents are kept rather than deleted because the reasoning in them is
real and some of it survives the pivot:

| Still useful | Why |
|---|---|
| `SETU-first-five-families.md` | Finding five real users and watching them is the right first move for any version of this. |
| `SETU-brand-positioning.md` | The tone and the audience did not change, only the promise. |
| `SETU-credentials-needed.md` | The accounts and keys checklist is mostly still accurate. |

| Superseded | Why |
|---|---|
| `01-caregiver-ecosystem-strategy.html` | The whole subject no longer exists. |
| `SETU-getting-real-caregivers-and-doctors.md` | Same. |
| `SETU-building-the-doctor-directory.md` | Same. |
| `SETU-zero-to-launch-handbook.md` | Its launch plan is a marketplace launch plan. |
| `SETU-feasibility-and-launch-plan.md` | Its model assumes visit revenue. CareHive is free. |
| `SETU-ai-provider.md` | The AI features were removed; no provider is called any more. |
| `SETU-functional-audit.md` | Audits modules that have been deleted. |
| `SETU-feature-roadmap-review.md` | Reviews a roadmap that no longer applies. |

The filenames keep the old codename. Renaming them would only make the history
harder to follow.
